About

Next-Generation Security

HYQUB is a payment wallet that protects each transaction with a post-quantum ML-DSA signature. Every payment is verified by two independent verifiers before the smart wallet executes it.

Cryptography & System Design

The Quantum Imperative

Classical asymmetric cryptography (ECDSA and RSA) faces existential vulnerability from Shor's algorithm. HYQUB deploys a hybrid dual-layer defense to protect digital transactions against current and future quantum adversaries.

The Quantum Threat

Shor's Algorithm & Harvest Now

Adversaries are actively storing encrypted data and classical blockchain transactions today to decrypt them once cryptanalytically relevant quantum computers arrive. Standard elliptic-curve signatures (secp256k1) will be forgeable in polynomial time.

  • ! ECDSA & RSA compromised by quantum period-finding
  • ! Long-term value storage and smart contracts at risk
HYQUB Hybrid Architecture

Dual-Layer Verification Gate

HYQUB bridges post-quantum security with EVM execution without requiring network-wide hard forks. Transactions are authenticated off-chain through lattice-based signatures before being committed to an on-chain smart account.

  • 1 Gate 1 (Off-Chain PQ): ML-DSA-65 lattice signature verified by 2-of-2 independent quorum
  • 2 Gate 2 (On-Chain EVM): ERC-4337 Smart Account validates approval token via validateUserOp()
Engineered for Reliability

Technology Stack & Tooling

HYQUB integrates battle-tested post-quantum cryptographic libraries, Ethereum account abstraction infrastructure, and asynchronous backend verification.

Post-Quantum Cryptography

Implements NIST FIPS 204 ML-DSA-65 (CRYSTALS-Dilithium) lattice-based digital signatures. Utilizes the system-level Open Quantum Safe (liboqs C library) combined with Python bindings for performant signature creation and dual-verifier quorum checks. Keystores are protected with scrypt key derivation and authenticated AES-GCM encryption.

ML-DSA-65 FIPS 204 liboqs C liboqs-python AES-GCM-256 scrypt KDF

Blockchain & Smart Accounts

Built on Ethereum Account Abstraction (ERC-4337). The HYQUBWallet contract validates user operation intents and executes payments with programmable velocity limits. Smart contract development, deployment, and testing are orchestrated using the high-performance Foundry suite (Forge, Anvil, Cast) with OpenZeppelin v5 primitives.

ERC-4337 Foundry / Forge Solidity 0.8.28 Anvil Local EVM OpenZeppelin v5 web3.py v8

Verification Engine & API

Powered by Python 3.14 and FastAPI for asynchronous, non-blocking transaction processing. Features strict Pydantic v2 data validation, SQLite session authentication with SHA-256 token hashing, idempotency enforcement, and a resilient market data ingestion pipeline (httpx2 client with automated Binance and Kraken failover).

FastAPI Python 3.14 Uvicorn ASGI Pydantic v2 SQLite Vault httpx2 Engine

Zero-Dependency Frontend

Constructed with pure HTML5, vanilla CSS, and native ES Modules. Zero bundlers, zero npm dependencies in production, and zero supply-chain risk. Features custom BigInt arithmetic for lossless Wei/ETH conversions (wei.js) and interactive, responsive SVG market trend visualizations (price-chart.js).
